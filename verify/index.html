How to check

The file. On a computer, run sha256sum file.apk (Linux), shasum -a 256 file.apk (macOS) or certutil -hashfile file.apk SHA256 (Windows). The result must match the checksum above.

The signature. With the Android SDK, run apksigner verify --print-certs file.apk. The certificate SHA-256 digest must match the one above. Any later beta of the same app is signed with the same certificate, so Android will only install an update that came from us.

Google Play builds are signed by Google Play app signing with a different key from the betas. Android will not install a Play build over a beta, or a beta over a Play build. Export a backup in the app, uninstall it, install the other build, then import your backup.
